# Kiefergelenk-3D

Interaktives 3D-Lehrmodell des Kiefergelenks der Praxis Dr. Paul Drehmann, Ingolstadt.

- Live: GitHub Pages dieses Repositorys (`index.html`)
- Einbindung auf der Praxis-Website per `<iframe>`
- `vendor/` enthält three.js r128 (MIT-Lizenz), damit beim Aufruf keine externen Server kontaktiert werden.

Lehrmodell, aus anatomischen Maßen konstruiert – Proportionen angenähert, kein Patientendatensatz.
